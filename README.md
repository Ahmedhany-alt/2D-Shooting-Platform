# Shooting Game – README

## Game Overview

A 2D shooting game where you fight enemies, collect coins and health items, and try to reach the exit door with the key.

> **Note:** The player animations and shooting system work correctly inside Godot, but they are currently not working properly on itch.io. We haven't been able to fix this issue yet, so screenshots showing these features inside Godot are included below.

## Main Menu

The main menu has two options:

- **Play:** Start the game.
- **Exit:** Close the game.

## Controls

- **WASD / Arrow Keys:** Move the player.
- **L:** Shoot.
- **Spacebar:** Jump. You can jump up to 5 times consecutively.

## Enemies and Health

- Enemies deal **1 damage** per hit.
- A special hidden enemy deals **3 damage**, equal to the player's entire health.
- The player starts with **3 health points**.
- Collect health items to restore health.

## Coins

Coins are scattered throughout the game and can be collected by touching them.

## Objective

1. Fight enemies and avoid taking damage.
2. Collect coins and health items along the way.
3. Find the key located in the **top-left corner** of the map.
4. Reach the door in the **top-left corner** and enter it with the key.

**Important:** Entering the door without the key still results in losing the game, so make sure to collect it first!

## Player Animations

The player has several animations and movements, including looking and shooting upward, crouching, sticking to walls (Wall Cling), and shooting. All these features work correctly inside Godot, but they are currently not working properly on itch.io.
